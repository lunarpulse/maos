### Lane A — digest admission (GPT P1-1, P1-2, P1-3 on round 1's F4)

**Final design** (`governed_digest_read.rs`, `maos-cohort/src/state.rs`, `worker_spawn.rs`, `maos-sso` discovery, `main.rs` governance):
1. *Before any cohort lock, no waiting*: `CohortManifestState::digest_admission_snapshot` reads the live manifest version (an `AtomicU64` that `apply_reissue` stores under the `cached` guard BEFORE it clears the grants) and whether `(requester, request_id)` is already admitted (new leaf-locked `admitted_index`, so the pre-check never waits behind a guard that holds the admitted-read lock). An already admitted request is NEVER resolved: it reaches the inner state with no resolution, which returns the duplicate ACK without running the guard (P1-3).
2. *Before any cohort lock, may wait (bounded by the verifier's wait)*: `CollectiveReadGovernor::resolve` for a NEW request only. `resolve_enterprise_principal` now returns a `ResolvedPrincipal` (principal + the assertion it was verified from).
3. *At commit, inside the cohort locks, never waiting*: (a) the inner state, after its atomic duplicate/capacity checks and before the guard, refuses typed (`CohortError::EDigestAdmissionStale`, text "admission is stale") when the live version differs from the step-1 version, so a v1 admission can never be published as a v2 grant (P1-1); the grant is stamped with the step-1 version, never a later read. A reissue racing the check either is visible to it or clears the grant afterwards (it needs the admitted lock this commit holds). (b) `govern` first calls `recheck_enterprise_principal`, which re-verifies the carried assertion through the new `IdentityAssertionPort::verify_without_refresh` (answered from the keys already held, against the verifier's own clock, never asks the refresher) and requires the same principal, then runs PDP, mint, audit, seal, SIEM; a key retired or key set / token expired while the request waited refuses typed ("resolved identity is stale at commit") (P1-2). A request that was admitted, then withdrawn (reply completed or reissue) between step 1 and commit is refused "withdrawn before commit; retry" (fail closed; never mints without a resolution).

New symbols: `IdentityAssertionPort::verify_without_refresh` (default = `verify`; documented: every implementor that can wait MUST override), `DiscoveringVerifier` override + `Shared::cached_key` (discovery.rs, additive, appended), `EnterpriseRuntime::reverify_principal_no_wait`, `worker_spawn::{ResolvedPrincipal, recheck_enterprise_principal}`, `CohortManifestState::{digest_admission_snapshot, note_admitted_request_at_version}`. `GovernedDigestReadPort::new` now takes `Arc<CohortManifestState>` (was `Arc<dyn DigestReadPort>`; the only production caller and the tests already passed the concrete state).
