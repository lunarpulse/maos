Concepts
Model inference on the Kimi API platform is billed on a pay-as-you-go basis, with no subscription plan. It differs from products such as the Kimi membership and Kimi Code. See the product comparison.
​
Billing Unit
Token: the basic unit of text processed by the model. A long word like “antidisestablishmentarianism” may be split into several tokens, while a common short word like “word” usually takes just one. For typical English text, 1 token is roughly equivalent to 3-4 characters. Use the Token Calculation API to get the exact token count of each call.
​
Billing Logic
Model inference APIs bill input and output tokens by usage. For K3 series models, cache writes are billed separately by TTL (5min / 1h); cached input is billed at the cache-hit price only, with no additional cache write charge. If you upload a document, extract its content, and pass the extracted content as model input, that content is also billed by usage. File-related APIs (file content extraction and file storage) are temporarily free: uploading and extracting a document alone incurs no file API charges. For tips on improving cache hit rates and choosing a TTL tier, see Best Practices for Context Caching.
