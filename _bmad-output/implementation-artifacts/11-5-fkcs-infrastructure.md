### Anti-canned discipline (the reason for opus-4-8 — L2/L3/L7/L8)
This story exists to make canned greens impossible. Every count/claim needs a per-item blind that reds it:
- **The diff-oracle (L2):** feed a `kernel_unchanged=true`/`abi_unchanged=true` flag alongside a real kernel edit → the oracle ignores the flag and REDs (the flag is not an input — Decision 7).
- **The negative control (L3):** blind `admit_spirit` to always-`Admit` → the negative-control-rejects leg reds (a stubbed admission cannot pass).
- **The cohort (L7/L8):** blind one proxy-Spirit's oracle snapshot → the derive-and-reconcile count reds (a `passed=N` summary cannot pass); label the cohort in-house proxy everywhere.
- **The frozen tag (L9):** capture the "before" snapshot on a dirty tree → the consistency leg reds (the checkout MUST be clean — mirror `abi-diff --diff-git-checkouts`).
Keep the tripwire legs **in-process/offline** (in-house proxy authors, local registry fixture, frozen-tag checkout) so they are real per-commit gates, not advisory-skipped (L6); any genuinely-live external-author/registry leg is an ADDITIONAL advisory leg.
