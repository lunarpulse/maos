## 2. What Went Well

1. **Kernel-Δ discipline held across an entire mesh epic.** Seven stories on ADR-054 and the only real kernel delta was a defect fix the net surfaced (12.5 `PostSwapMonitor` auto-reverting a drained hot-swap — a silent safety-guarantee falsifier on the epic closer). 12.1/12.2/12.4a/12.4b held true ZERO-Δ. Not scope creep — the tripwire working as designed.
2. **`check-cohort-mesh` is the strongest gate the project has built.** 35 legs, live on a real N=8 TCP mesh, every negative derive-and-reconciled with its own falsifier wired to its own leg (11.4b discipline). Distinct-cause assertions throughout (`ConcurrentFork` vs `VersionRegression`, `MemberLoss` vs `ConnectivityLoss`, `ForkAtSource` vs `Cycle` vs `SelfLoop`) — no cross-greening.
3. **The scout-first multi-round preflight caught day-one-fatal issues before a line was written.** 12.1 R3 found two blockers two prior rounds missed: a Cargo-forbidden dependency cycle (RR10, wouldn't compile) and a hard-fail mechanism that didn't exist to clone (RR11). 12.5's three rounds walked "missing node → backwards mechanism → circular guard." 12.4a's split disproved the original 12.4 premise entirely.
4. **The §A6 review net remained the binding control — and it earned it again.** Non-degradable on every consent/security/journey story. It surfaced 12.4a's 8 fail-open/lifecycle holes, 12.5's latent kernel defect, 12.4b's latent aggregation double-count, and 12.6's own detector still being defeatable by non-canonical syntax. Frontier-allowlist models (opus-4-8, gpt-5.6-terra/sol) mixed freely with the net as the compensating control — no opus dev mandate needed (E11-A1 posture validated).
5. **The identity-reflex family extended cleanly** into the cohort domain: manifest-authority-identity (12.1), acting-role-exact-match (12.2), halt-source-identity (12.3) — each derived from the live signature/emitter, each with its own proven-red.

## 3. What Was Hard / Systemic

1. **"A claim standing in for a control" was the epic's signature failure mode — eleven documented instances, one per story-plus.** Every story's own premise asserted a guarantee the code did not enforce; each was green until a scout read the code. 12.1 RR10/RR11; 12.2 P2 (union-scoped validator let a confused deputy through a `done` story); 12.3 ×4 (dead `PartitionTimeout`, per-ship `AtomicU64` dedup, zero-caller "daemon smoke"); 12.4a F3/F4 (no consent-gated read existed; production rupture sink was a `#[cfg(test)]`-only no-op); 12.5 R1/R7 (no version catalog; a re-pin mechanism with *backwards* teeth). **Identical to Epic 11's "vacuous-green."** The failure mode did not go away — the *countermeasure* is now reflexive, and it caught all eleven. **But the countermeasure is cultural discipline, not a mechanism** (Grumbal) — the exact thing that decays three epics deep.
2. **Gate-binding decay is now biting.** `CURRENT_PHASE = "v1_5"` is hardcoded across ~7 v2.0 gates and does double duty: it names GA progress *and* decides whether a CI leg blocks. At v1.5 those gates return advisory `Ok()` even when a leg reds. 12.1 had to hand-build a bespoke carve-out to make its own gate fail closed. We shipped a mesh with one binding gate next to seven paper ones. → **B1 (Option C).**
3. **`cargo fmt` drift silently re-pinned the kernel baseline and shipped un-caught into the next story's lap.** 12.2's fmt reflow drifted 23081→23082 despite 12.2's own gate passing green; 12.3 inherited the red and had to reconcile it. The "even a fmt reflow is a finding" discipline didn't fire at its origin. → **B4.**
4. **The three mechanical E11 action items slipped; the two planning ones landed.** A4/A5 (§15.10 ratification, epic generation) done — and they're why this epic had a foundation. A1's gate (never built), A2's retrofit (only the new gate got the pattern), A3's merge (never executed) all slipped. Same split every retro: **the plan gets done, the discipline mechanism gets deferred.**
5. **A3 was the root cause of the gate-binding decay — and it was ratified last retro.** External holds keep GA at v1.5 → `CURRENT_PHASE` stuck → gates advisory. The founder decouple directive was meant to break exactly this coupling; ratified, not executed. → **B2.**
