## Story

As a **MAOS operator running Marcus's 8-host Team Nexus (J3)**,
I want **each cohort member's locally-owned halt receipt to be shipped across the mesh as the reserved `cohort:halt-receipt` intent and recorded by an out-of-kernel observer that surfaces, for every member, either a received receipt or an explicit transport-level absence marker within the §7.2 window — without the observer ever gaining a path to resolve, resume, or override a halt**,
so that **a halt-on-conflict between two team members is visible mesh-wide as first-class receipt-presence/absence (feeding the day-30 digest, 12.4), while arbitration stays the Director's and the kernel remains the single halt owner.**

This story turns the `cohort:halt-receipt` intent class that Story 12.1 **reserved** (always-allowlisted by schema) and that Story 12.2 protected the **placement of** (the role gate sits *after* the reserved short-circuit, else halt receipts break) into a **shipped, observed** cross-agent signal. The kernel's halt machinery is **unchanged** — `invoke_halt`/`terminate_spirit` already produce and locally journal (I2) a `HaltReceipt`; 12.3 adds only the **out-of-kernel shipping courier** and the **out-of-kernel receipt-presence observer**. It does **NOT** implement the team digest / J3 day-30 scene (12.4), the no-surveillance posture (12.4), or cohort hot-swap / migration (12.5). It does **NOT** touch single-halt-owner logic, halt resolution, or the kernel at all.

### §A7 reflexes to name per new gate leg (Epic 12 gate discipline) — corrected per preflight P2-P6
- **absence-first-class reflex (P2/P2a/P3):** a member's absence is recorded ONLY when backed by an **actual probe (reserved manifest-PULL) `Err` TO that member** classified precisely — `A2AError::Io` (clean down) or `TransportFailed` with a `"timeout:"` message (partition); **PRESENT** = `Ok(())` or any mapped application-NACK. **NEVER a bare `TransportFailed`** (aliases a live peer's unknown NACK, P2a), **NEVER `PartitionTimeout`** (loopback-only), NEVER a broadcast failure to a *different* peer, NEVER a silent gap. A leg must pair a down-classify with a PRESENT positive so the classifier proves it distinguishes up-from-down, not just "some Err" (11.2b).
- **halt-source-identity reflex (P5):** each counted receipt's emitting member is the **authenticated `frame.from.host_id`** (proven == TLS `verified_peer` by `handle_intake_verified` before the arm runs), NOT a payload label — `HaltReceipt` has no host field. A forged source (unverified path, or `from` ≠ TLS peer) reds through the real presence read / is refused.
- **replay-dedup reflex (P4):** a duplicate receipt keyed on **`HaltReceipt.halt_id`** (stable payload id) does NOT inflate the presence count — NOT the A2A envelope `frame_id` (per-ship counter → dedup no-op). The dedup leg ships the SAME receipt twice; a double-count reds.
- **observability-not-arbitration reflex (P6):** the guarantee is the **dependency graph** — cohort ↛ kernel-core, so `HaltRegistry::resolve`/`KernelHaltResolver` are unreachable and any resolved receipt is inert. The chokepoint reinforces (single observer call site, in `handle_intake_verified`). A bug that adds a `maos-kernel-core` dep to the observer's crate reds `check-dependency-closure`; a bug that adds a second observer call site reds the chokepoint.
- **observer-wiring reflex (P7c) — the anti-silent-green:** "compile + daemon smoke" does NOT prove the composition wires the observer (no cohort daemon smoke exists; compile can't see injected-but-inert). A **transport-level test injects a RECORDING observer and asserts a shipped `cohort:halt-receipt` landed in ITS presence table** — a mis-wired/inert/wrong-instance observer reds it. The main.rs last mile is closed by single-object wiring (gate⟺observer, P7b), not by a nonexistent smoke.
- **spoof-proof-site reflex (P5r):** halt-receipt presence has no signature anchor (unlike reissue) → the observation MUST live in `handle_intake_verified`, the one place `frame.from==verified_peer` is proven; a receipt via the `transport.rs:671`/loopback door is not counted. A bug that moves the observer into the bare `handle_intake` arm (self-asserted peer) reds the source-identity leg.
- **derive-and-reconcile:** presence/absence is derived from the actual roster + actual shipped receipts + actual probe `Err`s, reconciled against the observer's real read — never a self-reported flag, never a literal "observed N".
