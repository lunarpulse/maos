## What Went Well

1. **Party-mode preflight moved governance *upstream* of code review.** Every fork on 8.11–8.15 was resolved unanimous **before** dev started. Code review then caught *implementation* gaps (copy-paste server-URI mapping in 8.14b, stub `handle_option_pick`, missing assertions) rather than re-litigating architecture. The team writes better code when the architecture is settled first.

2. **The in-proc Spirit→kernel bridge was solved once and reused six times.** Butler's pure Spirit-side lib + dev-dep orchestrator adapter (8.1; `ranged_recall` as a pure free-fn, cite via `maos_audit::query`) carried through all six reference Spirits with **zero `Ctx` ABI widening**.

3. **Charter enforcement is mechanical, not aspirational.** When 8.14a landed a kernel-core `policy()` getter, the team **rejected it outright** (use `issue_with_mediation` directly) — not "defer," not "refactor later." The zero-kernel-KLOC rule has teeth because it was tested and held.

4. **Oracle-audit discipline.** From 8.13's receiver-side wire-content oracle (`install_intake_sink` — proves cognition crossed the wire, not a constant) and codified in 8.15 (every Tier-1 oracle string traces to a named constant or typed production field). LLM-born strings are weather; named constants are contract.

5. **The live runtime actually lives.** `maos run` fires Butler's epistemic halt through production wiring (8.11); founder-loop runs over real CLI subprocesses with the 8.4 hand-INSERT deleted (8.12); Mira→Nash rides live TCP/mTLS with real mobile push (8.13); cross-host ConsentRupture is now **earned** by production code at the receiver intake-deny branch, not hand-inserted (8.13.1).

6. **Zero *silent* debt.** Sixteen carry-forward items, every one named, owned, and assigned a next-story home. This is the anti-pattern from Epic 5's "shipped done with 27 open findings."

## What Was Challenging

### 1. "Done" preceded integrated CI — green-at-HEAD reached by disabling gates (the headline)

All 18 stories were marked `done` in sprint-status **before CI ran on integrated `main`.** The first real Epic-8 CI validation (`d2d7252`, "first Epic-8 CI validation") kicked off a **six-round remediation marathon** (`d2d7252` → `0707f21`). The final green run (`27388044071`) was reached in round 6 by **disabling two advisory gates with `if: false`**:

- **`smoke-spirit-author-7-1`** — Epic-7 template bit-rot (cargo-generate ≥0.23 reserves `crate_name`; missing post-generate.rhai; `@maos/spirit-ts` unpublished). Not an Epic-8 regression.
- **`check-epic-6-bridge`** — the **Epic-6 §A2/§A3/§A5/§A6 debt beacon**, designed to exit 1 until those bridges land. **Four epics deep.**

This is the **Epic-7 §A5 finding repeating**: "green-at-HEAD" was named a precondition for Epic 8, and we reached epic-close by *parking* red gates rather than clearing them. The cross-epic law from prior retros holds: **gates that ship complete in one story hold; debt that depends on a future backfill decays.** The Epic-6 beacon is the canonical decaying promise.

### 2. Kernel baseline drifted unsummed (16263 records vs 21128 reality)

Story records claimed `16263`; the actual CI-pinned reality is **`21128`** (`t11_t12_chaos_absence.rs:179`). The live-runtime phase grew the kernel ~4.8k lines beyond what the per-story baselines tracked. Each story's "byte-identical / +N" claim was *locally* true, but the **aggregate growth was not being summed honestly** — CI remediation had to re-pin to 21128. There is no single enforced source-of-truth line count, so deltas can drift unnoticed across a multi-story phase.

### 3. Non-Claude models missed production-level gaps (caught by the net, not the model)

- **8.13 (`openai/gpt-5.5`)** hand-inserted a fake `ConsentRupture` row — *no emission path existed anywhere* in maos-a2a-core/tcp (grep-verified in review). Spun out as 8.13.1 (re-implemented on `claude-opus-4-8`).
- **8.14c (`kimi-for-coding`)** shipped a frame-id design (FORK 2 Option A1) that was structurally **unbuildable** — the kernel MCP adapter returns no frame id and there is no Spirit-side arbitrary-emit port. Party-mode **preflight** had to reground it (source-key join to journaled `McpInvocation` args).

Both gaps were caught — but by **party-mode preflight + multi-layer adversarial review**, not the model. This is Lunarpulse's `deepseek-v4-pro` memo generalized: non-Opus models are weak on async invariants, integration plumbing, and *systemic* (absence-of-path) reasoning.

### 4. The founder-class standalone-load gap surfaced three times and has no home

`maos run` cannot standalone-load founder-class `[class]` Spirits — `classify_spirit` short-circuits at admission (8.12 FORK B). This forced J1 resume-continuity to ship as a **Grade-B smoke stub** (8.15). The gap recurred in 8.12, 8.14c, and 8.15, and it is **not in the Epic 9 stub** (Epic 9 is audit/compliance/operator). It gates founder-class Grade-A, J1/J4 upgrades, and multi-tool orchestration that operator-productionization (9.4) implicitly assumes.

## Key Takeaways

1. **Party-mode preflight is the real quality engine** — it caught both non-Opus production gaps before code review even started. Make it mandatory whenever a non-Opus model touches correctness-critical work (§A6).
2. **The charter has teeth** — the 8.14a `policy()` rejection proved zero-kernel-KLOC is enforced, not aspirational. Keep embedding charter checks in story acceptance, not later gates.
3. **Green-at-HEAD decays unless epic-close depends on it.** Four epics running, we reach the line and park red gates. The structural fix is §A5: epic-close is contingent on integrated CI green with zero disabled gates.
4. **Baselines must be summed, not just locally asserted.** 16263-vs-21128 is the cost of per-story "byte-identical" claims without one enforced aggregate (§A4).
5. **Sequence homeless value before it's lost** — the multi-Spirit scheduler became Story 9.6 the moment it was named, exactly the discipline that kept Epic 8's debt ledger free of silent items.
