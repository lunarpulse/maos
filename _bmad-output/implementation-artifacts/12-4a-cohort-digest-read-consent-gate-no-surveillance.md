## Story

As a **MAOS operator running Marcus's 8-host cohort (J3)**,
I want **the Digest Spirit's cross-member reads to travel over a NEW, deliberately non-reserved `cohort:digest-read` A2A intent that is consent-gated at both seams (the reader's send-allowlist + the target's accept-allowlist, acting-role exact-match), where a read outside the consent matrix is refused by the target AND made visible to that target member through a consent rupture that actually reaches its transparency log**,
so that **"nobody reads another member's data without consent" is a demonstrable, auditable runtime control on the real N=8 mesh — a refused, surfaced query, exactly as ADR-054 §8 specifies — and not a claim standing in for a control.**

**This story exists because the preflight proved the original 12.4's premise was false.** Scout-verified at HEAD `e17a1056`: (1) the 12.3 receipt-presence stream rides the **reserved** `cohort:halt-receipt` intent, which **bypasses both consent seams AND the cohort role/version overlay** (`router.rs:507,551,566,634,1002`) — so it is *not* a consent-gated read and AC "reads only consented topics" cannot attach to it; (2) **there is no consent-gated cross-host read intent anywhere** — A2A is delivery-only (`METHOD_IAC_DELIVER`, response `AckBody` carries no data, `json_rpc.rs:114,205`), `log.recall` is local emitter-scoped (`log_recall.rs:282`, recipient-side "deferred, not landed"), `memory.share` does not exist; (3) `emit_consent_rupture` is a **production no-op** — the `rupture_sink` is installed only in `#[cfg(test)]` (`router.rs:1436,1482`), so a refused read reaches the target **nothing** in prod. 12.4a builds the missing primitive and wires the missing sink. It does **NOT** build the Digest Spirit, the narrative render, or the J3 scene (12.4b). It does **NOT** touch the kernel or `maos-domain`.

## Acceptance Criteria

1. **NEW non-reserved `cohort:digest-read` intent, consent-gated at BOTH seams (ADV-054-3 + §8).** Introduce `cohort:digest-read` as a normal typed A2A intent — **deliberately NOT added to `is_reserved_cohort_intent` (`crates/maos-a2a-core/src/router.rs:507`)** so it is fully evaluated by `send_admits` (`:549`) on the reader side, `accept_admits` (`:564`) on the target side, AND the cohort overlay `cohort_consent_decision` (`:514`) with **acting-role exact-match** (never any-role OR). Wire form is colon-kebab `cohort:digest-read` (valid per the grammar at `crates/maos-domain/src/invariants/i8.rs:85`; dots are invalid). **ZERO `maos-domain` touch** — it is a string intent flowing through the existing seam, not a new `FramePayload` variant or `A2AJsonRpcRequest` field (F1 idiom, `check-service-boundary` must NOT reconcile). A `cohort:digest-read` that accidentally lands in `is_reserved_cohort_intent` would BYPASS consent — that is the exact failure this AC forbids (a reserved read is an ungated read).

2. **A cross-member "read" = ONE consent decision (the target's accept-gate) + an intrinsic correlated reply — NOT two independent gates (closing-round fix).** Because a `METHOD_IAC_DELIVER` response is an `AckBody` with no data payload (`crates/maos-a2a-core/src/transport/json_rpc.rs:114`), the reply is physically a separate outbound frame — but it is authorized by the ADMIT, **not re-gated by a second send-allowlist check.** The flow: the reader sends a `cohort:digest-read` request carrying a **`request_id`**, naming the scope it wants → the **target's accept-gate** (`accept_admits` + cohort overlay) is the **single consent decision**: **DENY → rupture, no data** (AC3); **ADMIT → the target replies with the summary it chooses, tagged with the same `request_id`.** The reply is the *intrinsic fulfillment of an admitted request* — the send-exemption is scoped to "a reply correlated to a request I admitted, to the **authenticated** requester (`frame.from` == TLS peer)," never a free-standing unsolicited push. The target controls exposure via (i) the admit and (ii) the summary content — both the target's, neither a silent state. **This single-decision model closes three holes the split story left open:** the **dead-air** (admit-the-ask/deny-the-answer, live in the 12.2 `T_stale` skew window), the **consent side-channel** (admitted-but-silent ≠ denied leaks which topics exist-but-are-withheld), and **replay** (AC below). The reply carries a **typed summary payload** (member self-reported daily stats — frame count, halt count, conflicts) serialized into the **existing `TelemetryEvent` carrier** (the 12.3 halt-receipt idiom, `crates/maos-cohort/src/distribution.rs:119`) → **ZERO `maos-domain` touch** (a `maos-cohort` struct in `data`, not a new `FramePayload` variant). Both request and reply are journaled to the I2 TL (extend `CohortAuditEvent`, `crates/maos-cohort/src/audit.rs:19`). This is one intent + one correlated reply — **NOT a general A2A request/response framework** (Dana).

2b. **`request_id` replay-dedup — define a stable payload id (there is none today; scout-confirmed).** The A2A envelope `frame_id` is a per-ship `AtomicU64` that resets on courier reconstruction (`distribution.rs:94`, `halt_receipt.rs:176`) and there is **no intake dedup at all** — so a replayed/duplicated summary reply would double-count. Mirror the ONLY payload-stable dedup in the codebase (12.3 `HaltReceipt.halt_id`): the `cohort:digest-read` request mints a **stable `request_id`**; the reply carries it; the digest is **idempotent per `request_id`** (a `HashSet`, like `observe_receipt`'s dedup at `crates/maos-cohort/src/state.rs:583`). NEVER dedup on the envelope `frame_id` (the 12.3 P4 silent-no-op). The `request_id` does triple duty: request↔reply correlation, replay-dedup, and the "this is an admitted reply" anchor for AC2's send-exemption.

3. **Surveillance-negative control: an out-of-matrix read is REFUSED by the target AND VISIBLE to that target member (ADR-054 §8, spec verbatim).** A `cohort:digest-read` for a (peer, acting-role, topic) NOT in the reader's tuples → the target's accept-seam denies as `CohortConsentVerdict::Deny(reason)` (`router.rs:1022`) → `emit_consent_rupture` fires (**already wired by Story 12.2 at `router.rs:1024`** — do NOT re-add it) → the rupture lands in the **target member's transparency log** (see AC4) → **no data is returned.** The guarantee is *gated + visible refusal*, which IS the no-surveillance guarantee (the room rejected "no pull path at all" — it makes this control vacuous and contradicts the spec). Derive-and-reconcile from the **real `Deny` verdict** + the **real target-side journal entry**; a data-returning path, a silent empty read, or a rupture that never lands each reds the leg **through the real verdict/journal**, never a side flag.

4. **Wire the PRODUCTION rupture sink + prove the target can QUERY it — the real F4 fix (the draft's F4 was stale).** `emit_consent_rupture` early-returns when no sink is installed (`router.rs:280-286`); `install_rupture_sink` (`:256`) is called **only inside `#[cfg(test)]`** (`:1436`, `:1482`) — so today a refused cross-host read gives the reader a wire NACK but the **target journals NOTHING** (verified: no other TL insert on the accept-deny path). **12.4a wires `install_rupture_sink` into the production composition root** (`crates/maos-bin/src/main.rs` cohort daemon / `maos-a2a-tcp` bind path) so the accept-side rupture — already emitted since 12.2 at `router.rs:1024` — is journaled as `FrameKind::ConsentRupture` on the **denier's host, which IS the target member** (`from = denier = the member whose data was queried`, `router.rs:319`). **The "visible to the affected member" read surface already exists** (scout-confirmed) and must be shown working end-to-end: the target queries the rupture via `maosctl audit query --frame-kind ConsentRupture` / `maosctl audit posture-delta` (which explicitly surfaces `ConsentRupture`, `crates/maos-cli/src/cli.rs:417`) / `LogRecallPort::recall{kind: ConsentRupture}` — and because log-recall is **emitter-scoped** (`crates/maos-domain/src/log_recall.rs:249`) and the emitter is the denier=target, the record is visible to the **target member** (not the querier). **This is the load-bearing line between "no-surveillance is claimed" and "no-surveillance is true."** Prove the sink is live: a refusal on the real mesh lands in a RECORDING target journal AND is returned by the target's audit query (the 12.3 P7c wiring-proof analogue — a stored-but-inert `Arc` compiles; "wired" ≠ "the row is queryable by the member").

5. **`check-cohort-mesh` mechanism legs — proven-red, derive-and-reconcile, LIVE at N=8 over real TCP.** New always-binding legs appended via the whole-set hard-fail loop (`xtask/src/check_cohort_mesh.rs:338`; each exactly one `--exact` `--ignored` live-TCP test per the vacuous guard; `CURRENT_PHASE` stays `"v1_5"`; `AlwaysBinding` does not exist yet — F6): (a) **consented read admitted** — an in-matrix `cohort:digest-read` is admitted and the target replies with its `request_id`-tagged summary; (b) **surveillance-negative** — an out-of-matrix read is denied AND the rupture is journaled on the target's host AND returned by the target's `audit query --frame-kind ConsentRupture`, no data returned; (c) **rupture-sink-wired proof** — a refusal on the real mesh is recorded by a live target journal + queryable (a stubbed/no-op sink reds — the anti-silent-green leg); (d) **anti-canned** — a **re-signed** manifest with a *changed* digest-read tuple flips the admit/deny verdict through the gate's own comparator (mint via `CohortManifest::signed_with` + the pinned authority key, the `t_12_2` mutate-and-re-sign precedent, `manifest.rs:378`; a static verdict reds); (e) **replay-dedup** — the SAME `request_id`-tagged summary reply shipped twice does not double-count (idempotent per `request_id`, the 12.3 `halt_id` precedent; dedup on the envelope `frame_id` is a silent no-op — reds if used). All on the real N=8 `build_mesh_n` mesh (`crates/maos-a2a-tcp/tests/support/mod.rs:451`, `t_12_1_cohort_mesh.rs` precedent) over **real TCP on the loopback interface** — NOT the loopback *adapter* (which self-delivers, `crates/maos-a2a/src/adapter.rs:82`, cannot bridge two members; F1). These legs **run and BLOCK in CI** (the N=8 leg pattern is `--ignored`-gated + gate-owned, hermetic on `ubuntu-latest`, not advisory — scout-confirmed). §A7 reflexes named per leg.

6. **ZERO kernel-Δ @23082, verified.** The new intent lives in `maos-a2a-core` (a string const + existing seam evaluation); the sink wiring lives in `maos-bin`; the journal extension in `maos-cohort`. **No `crates/maos-kernel-core/src/**` line moves; `maos-domain` stays frozen** (no new frame variant/field — `check-service-boundary` must NOT reconcile; a reconcile is a finding). `check-kernel-baseline` (23082), `check-empty-kernel`, `check-dependency-closure` (`maos-cohort`/`maos-a2a-core` outside the kernel+domain closure) green. **§A6 SECURITY net NON-DEGRADABLE** (consent + surveillance). §A7 no-surveillance reflex: the guarantee is a real `Deny` verdict + a real target-side journal entry; a planted unconsented read that returns data, or a refusal the target cannot see, reds the gate.

### Architecture basis
- **ADR-054 §8** (`docs/adr/ADR-054-cohort-mesh.md:71-73`): "reads only consented topics under its own per-(peer,role) tuples; every cross-member read is consent-checked and journaled; … a surveillance-negative control (an out-of-matrix digest query refused and visible to the affected member)." — the AC1/AC3 mandate, now backed by a real primitive.
- **ADR-054 §5 / ADR-012** (`:59-61`): acting-role exact-match, confused-deputy — the new intent inherits this evaluation.
- **J3 §10.7.1** (`prd/user-journeys.md:217`): "nobody read each other's transparency logs without consent" — reads-with-consent are expected; the guarantee is gated + visible-refusal.

### §A7 reflexes per leg
- **no-surveillance reflex:** an out-of-matrix read reds through a real `Deny` verdict + a real target-side journal entry; a data-return or invisible refusal reds.
- **sink-is-live reflex (P7c analogue):** the rupture must land in a RECORDING target journal; a stubbed/no-op/compile-only sink reds. Do not cite "wired" — prove delivery.
- **anti-canned reflex:** a blinded consent-matrix change flips the admit/deny through the gate's comparator; a static verdict reds.
- **reserved-intent reflex:** `cohort:digest-read` must be gated — a test proving it does NOT bypass via `is_reserved_cohort_intent` (else it's an ungated read).

### Prior-story traps
- **Reserved = ungated (12.3 P4).** The whole point of this story is a NON-reserved read. If `cohort:digest-read` lands in the reserved set, AC1/AC3 are vacuous.
- **Sink-as-wiring-proof (12.3 P7c, the fifth silent-green).** "Installed the sink" ≠ "the rupture lands." Prove delivery to a recording journal.
- **Layering barrier (12.3 P1).** No `maos-kernel-core` dep in `maos-a2a-tcp` (`t12a`); no loopback shortcut (self-delivers).
- **Vacuous-count (11.2a P1).** Derive verdicts from the real matrix + real frames; reconcile against the real verdict/journal.
- **Expect a second adversarial pass** (11.1a/b ~22 patches; 12.1-3 multi-round). §A6 net non-degradable.
