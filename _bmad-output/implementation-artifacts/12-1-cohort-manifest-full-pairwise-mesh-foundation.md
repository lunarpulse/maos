## Story

As a **MAOS operator declaring a team of agents (Marcus's 8-host Team Nexus, J3)**,
I want **a single Ed25519-signed cohort manifest that declares the members, roles, and consent matrix of a team and deterministically drives a full-pairwise A2A mesh of the existing bilateral channels**,
so that **a cohort runs as one governed team — no peer discovery, no DHT, no gateway — with membership and trust changes expressed only as signed manifest re-issues, and every member provably enforcing the same signed roster.**

This is the **foundation** story for Epic 12: it lands the manifest schema, the mesh composition, the authority/re-issue discipline, the staleness ceiling, and the `check-cohort-mesh` gate core legs. It does **NOT** implement per-(peer,role) consent *evaluation* (Story 12.2), halt receipts (12.3), the team digest / J3 day-30 scene (12.4), or cohort hot-swap / migration (12.5). 12.1 *declares* the consent matrix in the schema and parses+validates it; 12.2 evaluates it at the A2A seam.

## Acceptance Criteria

1. **Cohort manifest schema v1 (signed TOML).** A versioned manifest declares: members (`host_id`, pinned leaf-cert fingerprint matching the §7.2 TOFU pin, declared roles), the per-(peer,role) consent matrix as **separate send/accept tables** (no transposition ambiguity), the genesis cohort-authority `{ keys, threshold }`, the two schema-mandatory reserved always-allowlisted intent subtypes `cohort:manifest-reissue` and `cohort:halt-receipt`, a **signed `t_stale_secs`** (AC4), and a **strictly-monotonic integer `version`**. **Genesis trust (R1):** each member holds the authority pubkey **operator-provisioned out-of-band** (same posture as the §7.2 cert-fingerprint pin); the manifest's declared authority MUST equal the member's pinned key or the manifest is refused → typed **`ECohortAuthorityUnpinned`** — a v1 cannot self-declare its own trust root. **Set-valued pin during rotation (RR5, reconciles ADR-054 §2's one-generation-overlap):** the pinned authority is a **set** — `{current}` in steady state, `{current, next}` during an operator-declared rotation window (the §7.2.1.a one-generation-overlap idiom the ADR already invokes for this key). "Declared authority ∈ pinned set" is the acceptance test; a strict *single-key* equality would refuse the legitimately-rotated key and **brick rotation** (the fail-closed-against-the-legitimate-next-thing trap). Post-overlap, the retired key drops from the set and manifests signed by it are refused. **New config surface (RR4, code-verified):** there is **no existing field** holding an Ed25519 authority pubkey — `cert_fingerprint` is a per-peer *TLS-cert hash*, not a 32-byte cohort-wide signing key. This story adds a **new out-of-kernel cohort-level pin surface** (a `maos-cohort` config struct, or a new cohort field — NOT a per-peer `A2APeerConfig` field, since the authority is cohort-wide) + a provisioning runbook line (§15.7 custody). Still zero-kernel-Δ, but it is a *new surface*, not "free / same posture." **k-of-n (R2, Lunarpulse-ratified):** the schema keeps `threshold` for forward-compat but v1 **rejects `threshold > 1` at parse** → typed **`EUnsupportedAuthorityScheme`** (single-key is the genesis default, §15.11 Fork 2; real k-of-n verify is a follow-up with its own proven-red — never accept-and-single-verify). The manifest is Ed25519-signed by the cohort authority over a **canonical, domain-separated, length-prefixed** byte pre-image (the `to_canonical_bytes`/`SIG_DOMAIN` idiom; copy the `test_boundary_shift_no_collision` shape). Parse + schema-validate + signature-verify all live in a new out-of-kernel crate `maos-cohort` (depends on `maos-a2a-core` + `maos-domain`, never `maos-kernel-core`). **Schema-validate MUST also enforce referential integrity (RR-min):** every consent-matrix tuple's peer ∈ declared `members` and role ∈ that peer's declared roles — a dangling peer/role in the matrix is a **parse-reject here** (typed error), never inherited un-anchored by 12.2's evaluator.

2. **Full-pairwise mesh — smallest-watchable-first.** The manifest deterministically generates each host's `Vec<A2APeerConfig>` (its N−1 peer edges). Demonstrated in two rungs: **(a)** a hermetic **N=3 minimal-cohort watchable smoke** (3 bilateral channels — the smallest ADR-003 "three or more" mesh) on the journey harness, then **(b)** the **N=8 → 28-bilateral-channel** full-pairwise mesh over real `TcpA2ATransport` sockets. Wire format, mTLS+TOFU semantics, and logical-clock discipline are **unchanged** (a mesh link *is* a §7.2 bilateral channel). Membership changes are manifest re-issues, **never** runtime negotiation. **Count discipline (RR1, code-verified):** full-pairwise at N=8 is **28 bilateral channels = N·(N−1)/2**, equivalently **56 directed dials/handshakes = N·(N−1)** (each channel dialed both directions; self-dials excluded). The earlier "64 handshakes" figure was **wrong** — 64 = N² counts self-dials the harness explicitly skips — and is expressly forbidden by AC5's derive-and-reconcile rule; the gate **derives `N·(N−1)` from N**, never quotes a literal. **Harness reality (RR2, code-verified):** `directed_dial_sweep`/`pair_ok` are **local to `t_10_4b_rotation_real_timing.rs`** (hard-wired to a 3-element `const HOSTS` array → **panics for N>3**), **not** in `support/mod.rs`, and **11.3 does not use them** (11.3 is hub-and-spoke `concurrent_dial_pairs`+`hub_pairs`, `2·(N−1)`, not full-pairwise). The N=8 full-pairwise sweep is therefore a **new** all-`i≠j` sweep (56 directed dials) written on `build_mesh_n` (`support/mod.rs`) + `concurrent_dial_pairs` — do NOT "reuse `directed_dial_sweep`". Measure the 56-dial wall-clock at Task-0 and disclose.

3. **Manifest authority + re-issue discipline (ADV-054-1).** Only the genesis authority may sign a re-issue. The signature is verified against the **operator-pinned genesis authority key set** (AC1/R1 + RR5) — **never** a key carried in the manifest body, and **never** re-derived from the re-issue's own declaration (the "forgery is a one-liner" rule; the trust root is the pinned genesis key for every version, including v(n+1)). A member refuses a non-authority signature, a version regression, **or** a concurrent valid fork → typed **`ECohortManifestFork`** carrying a **`reason` discriminant `{ NonAuthoritySigner, VersionRegression, ConcurrentFork }`** and naming **both** versions (R3 — the gate asserts the *specific* cause, not "some fork error"). Re-issue is journaled to the authority's TL; **each member journals its own acceptance of v(n+1)** to its local TL (per-member adoption is observable, not assumed). **Honest fork guarantee (RR7 — this is a no-consensus CRDT mesh, not Raft):** `ConcurrentFork` is detectable **only at a node that receives *both* conflicting v(n+1)s.** If fork-A reaches member 1 and fork-B reaches member 2, each sees one valid, monotonic v(n+1) and neither raises — the mesh has split *silently*, every node individually green. So the guarantee is: same-version-conflicting-bytes is **caught locally where both are seen**; cross-node divergence is **bounded, not prevented** — by single-authority-writer discipline + `T_stale` re-convergence (AC4). AC3/ADR-054 must **state this**, not imply mesh-wide fork-*prevention* (an operator reading "refuses concurrent fork" as a safety property that stops a split would be wrong). The L2 gate leg (AC5) tests the *sees-both* node and stays exactly as specified.

4. **Distribution + staleness ceiling (ADV-054-2), fail-closed.** v(n+1) propagates as the reserved always-allowlisted `cohort:manifest-reissue` subtype (push by authority, **pull-on-connect fallback**). **Two-layer authorization (R4):** always-allowlisting is **transport-admission only** — it lets a reissue frame *through consent* to be evaluated; **issuer authorization is the signature verify against the pinned genesis authority** (AC3). A reissue frame from a non-authority is **journaled as a rejected-reissue observable**, never silently dropped (a member spamming forged manifests must be *visible*, not swallowed — the 11.4b error-swallow lesson). A member that cannot confirm it holds the current version within **`T_stale` (default = §7.2's 30s partition window × 4 = 120s, a signed per-cohort field)** marks its cohort links **degraded** and **refuses new consent-sensitive frames under the stale matrix** (fail-closed, Story-8.8 posture); a member revoked in v(n+1) is refused mesh-wide within `T_stale`. **Bounded signed field (RR6, fail-closed integrity):** `t_stale_secs` is authority-*tuned within* a range the **code owns**, never authority-*set* — parse-time clamp to a code-constant `[T_STALE_MIN, T_STALE_MAX]` (floor at/near the 30s partition window; a hard operational ceiling), reject out-of-range → typed **`ECohortStaleBoundViolation`**. Without the clamp a careless/compromised authority signs `t_stale_secs = 31_536_000` (1yr) and **silently disables fail-closed staleness mesh-wide** — a revoked member stays live for a year. The ceiling that constrains the signer must **not itself be signer-controlled** (a signed field may tune *within* code-owned bounds, never *define* them). This clamp is a parse-reject in AC1's schema-validate. **Single chokepoint (R5) via a port trait — NOT a direct type call (RR10, code-verified circular-dependency trap):** the router lives in `maos-a2a-core`; `CohortManifestState` lives in `maos-cohort`, which **depends on** `maos-a2a-core`. So the router **cannot name `CohortManifestState` directly** — `maos-a2a-core → maos-cohort → maos-a2a-core` is a Cargo-forbidden cycle. Resolve by **dependency inversion, copying the crate's own `Arc<dyn TofuPinStore>` seam** (`router.rs:128`, trait at `tofu.rs:72`, impl `TofuPinningVerifier` in `maos-a2a-tcp`, injected at `TcpA2ATransport::bind` `transport.rs:163`): define **`trait CohortManifestGate: Send + Sync { fn is_current(&self, …) -> bool }` in `maos-a2a-core`**, hold it on `A2ARouterCore` as `Arc<dyn CohortManifestGate>`, **implement it in `maos-cohort`** over `CohortManifestState`, and **wire it at the `bind`/`maos-bin` composition root** (same shape as `CollectiveMemoryPort`, 10.4b). The chokepoint is then the port method the router queries; a static caller-enumeration grep-proof enumerates *its* callers as the sole route (the 11.2b `read_path_chokepoint.rs` discipline, composed with cryptographic verify).

5. **`check-cohort-mesh` gate — core legs, anti-canned, real per-commit tripwire.** A NEW standalone xtask gate (cloned from `check_scale_churn.rs`, per-leg independence) with at minimum: **(L1) manifest round-trip with cross-issuer verification** — the manifest is produced by one code path and verified by an **independently-derived verifier** (ADR-049 independence); a **mismatched/unpinned-authority falsifier** must RED it (R1 — a v1 whose declared authority ≠ the pinned key is refused). **(L2) concurrent-re-issue proven-red** on a REAL fork (two authority-signed v(n+1)s) asserting **`reason == ConcurrentFork` specifically** (R3), with a distinct **version-regression** fixture asserting `reason == VersionRegression` (neither greens on the other's scenario). **(L3) stale-member leg** — a member revoked in v(n+1) refused mesh-wide within `T_stale`. **(L4) kernel-abi-diff** (`check_kernel_baseline::run(false)`). **Scale (R6 + RR8 + RR11):** both the **N=3 hermetic smoke AND the N=8 real-socket mesh** (56 directed mTLS handshakes — RR1) block **per-commit at HEAD**. **The mechanism must be BUILT — it does NOT exist to clone (RR11, code-verified):** in `check_scale_churn.rs`/`check_escape_detector.rs` a leg that **ran and failed** (real red) at `CURRENT_PHASE="v1_5"` flows to the advisory branch and returns **`Ok(())`** — it does NOT fail CI; the *only* phase-independent hard-fail is the **vacuous-green guard** (`check_scale_churn.rs:365-383`), which fires **only on 0-test legs**, never on a real red. **The cited "11.4b seccomp" precedent is itself advisory at v1_5** (`check_escape_detector.rs` disposition `{…,v2_0=blocking}`, `CURRENT_PHASE="v1_5"`) — so it is NOT a copyable per-commit-block precedent. Resolution: **add a NEW carve-out** — an unconditional `if !leg.green { return Err(...) }` for the **designated always-binding legs** (N=3, N=8, concurrent-fork, version-regression, unpinned-authority falsifier), placed **before** the `oracle_green`/`blocking_now` disposition branch, modeled on the vacuous-guard's *placement* but triggering on `!green` (real redness), not vacuity. **Phase-ladder (RR8):** `PHASE_ORDER`/`CURRENT_PHASE` are **per-module Rust consts** (duplicated across ~10 gate modules), *not* `gate-registry.toml` keys; a purely disposition-driven gate is **advisory** until `CURRENT_PHASE` reaches its blocking phase. So (i) the designated legs bind via the RR11 carve-out (real tripwire, independent of phase); (ii) add `"v2_2"` to *this gate's* `PHASE_ORDER` const + disposition `{v1_0=adv, v1_5=adv, v2_0=adv, v2_2=blocking}` for the ship-gate ladder + keep `v2_0="blocking"` so the registry-defect check (`:346`) passes; (iii) **do NOT globally advance `CURRENT_PHASE`** as a 12.1 side effect. **Note (RR11 consequence):** this makes `check-cohort-mesh` the **first gate that actually binds at HEAD** — every Epic-11 v2.0 gate is currently advisory-at-v1_5. That is deliberate (lead-by-example, retro "gates compound") but flags a separate project question: whether the Epic-11 gates should get the same carve-out or the phase should advance. Counts **derive-and-reconcile** `N·(N−1)` from N (never a literal — the "64" was wrong, see AC2). **Manifest-authority-identity reflex (RR3, Ed25519 has no key-recovery):** the accepted manifest's signature **MUST verify under the operator-pinned genesis key set** — you *cannot* "derive the signer from the signature" (there is no Ed25519 `ecrecover`; the pubkey is an *input* to verify, RFC 8032). The falsifier: a forged/wrong-authority signature **fails to verify under the pinned key** and REDs the round-trip leg through the gate's own comparator. An *attempted* leg that ran 0 tests **hard-fails** (vacuous-green guard). Absent/unmeasured → **BLOCK at the v2.2 ship gate**.

6. **ZERO kernel-Δ @23081, verified.** No line changes under `crates/maos-kernel-core/src/**` (mesh = composed bilateral primitive + manifest + reserved-intent reservation, all out-of-kernel). `check-kernel-baseline` (23081), `check-empty-kernel`, `check-service-boundary`, and `check-dependency-closure` (the new `maos-cohort` crate stays outside the kernel dependency closure) all green. ### Prior-story traps to avoid (the "vacuous-green mutates" family — retro §9.2)
- **Derived-but-loopback-trivial (11.3's major trap).** Sub-second loopback events pass any time floor trivially — **the teeth are the falsifier, not the clean pass.** Any timing/latency floor loopback can't physically exhibit is a REPORT-advisory regression tooth (loud "⚠️ EXCEEDED" banner), not a v2.2 BIND. Non-degeneracy asserted on RAW nanosecond deltas (seconds-rounded = 0 on loopback), ALL samples distinct.
- **Vacuous-count P1 (11.2a's signature failure).** Never assert "N members/channels" from a literal — derive from the actual mesh/manifest and reconcile against the distinct-identity set. 11.2a shipped this P1 *even under §A6* on opus-4-6 → pre-book Test-Infra + runtime layers regardless of model.
- **Tautological falsifier (11.2b P2 / 11.4b D1).** A blind that `+=0`, or filters a set it then re-counts, is theater. The falsifier must drive the REAL metric input a downstream contract consumes (e.g. a forged authority signature must RED the round-trip leg's own comparator, not a side flag). **Every named falsifier gets its OWN per-leg-independent gate leg** (11.4b split 8→9 legs when a falsifier had no leg).
- **Error-swallow (11.4b P1).** A verify/probe `Err` mapped to "0 problems" is a false-green. Return `Result`, distinguish a broken check from a clean one.
- **Origin ≠ authorization (11.2a orphan).** "Manifest signature valid" (origin) ≠ "member authorized in the cohort" (authorization). Don't let a validly-signed manifest launder an unauthorized member; if authorization provenance is out of scope, say so, don't conflate.
- **Atomic delete-vs-keep (10.4c).** 12.1 adds no canned scaffold to delete, but if any placeholder is introduced it must be removed with its synthetic tests + CI job in the same PR.
- **Advisory = test returns `Ok` on breach + WOULD-HAVE-BLOCKED banner to `$GITHUB_STEP_SUMMARY`**, NOT job-level `continue-on-error` (the aggregate fails on `contains(needs.*.result,'failure')`).

### Architecture ambiguities resolved here (arch text is silent — 12.1 decides)
- **Manifest TOML grammar** is under-specified in §15.2 → Task 1 defines it (concrete field names above).
- **Genesis trust (R1, party-mode-hardened):** the v1 authority key is **operator-pinned out-of-band** at each member (same posture as the §7.2 cert fingerprint pin; custody per the 9.4b runbook, §15.7). TOFU-on-first-manifest is NOT used for the authority key. A manifest whose declared authority ≠ the member's pinned key is refused (`ECohortAuthorityUnpinned`) — this closes the genesis circularity (a v1 self-declaring+self-signing its own forged authority). The derive-from-claimed-identity rule applies only to *members'* certs, never to the authority root.
- **`ECohortManifestFork` (R3):** carries a `reason` discriminant `{NonAuthoritySigner, VersionRegression, ConcurrentFork}` + both versions, so the gate asserts the specific cause (no tautology where the concurrent-fork leg greens on a version-regression fixture).
- **k-of-n (R2, Lunarpulse-ratified):** v1 keeps the `threshold` field for forward-compat but rejects `threshold > 1` at parse (`EUnsupportedAuthorityScheme`); real m-of-n verification is a clean follow-up with its own proven-red — never accept-and-single-verify.
- **`T_stale` = 120s default**, expose as a per-cohort manifest field (`t_stale_secs`, default 120) so it is signed, not host-local config — **but clamped at parse to code-constant `[T_STALE_MIN, T_STALE_MAX]` (RR6)**: a signed field tunes *within* code-owned bounds, never *defines* them (else the authority signs away its own fail-closed staleness). Out-of-range → `ECohortStaleBoundViolation`.
- **Authority-key pin is set-valued (RR5):** `{current}` steady-state, `{current, next}` during operator-declared rotation overlap (§7.2.1.a idiom, which ADR-054 §2 already invokes for this key). Strict single-key equality would brick the ADR's own rotation clause.
- **`ConcurrentFork` is bounded-not-prevented (RR7):** detected only at a node seeing both forks; cross-node divergence contained by single-authority-writer + `T_stale`, not eliminated (no-consensus CRDT, no Raft — the ratified posture). State it; don't claim mesh-wide fork-prevention.
