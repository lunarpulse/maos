# MAOS

> Founding-sprint substrate; CI gates ship before kernel code.

MAOS (Multi-Agent Operating Substrate) is a runtime for safe, auditable multi-agent systems.
This repository contains the founding-sprint workspace — a deliberately minimal scaffold whose
only job is to exercise the build-discipline gates that enforce the eight Foundational
Commitments and invariants I1–I14.

The full 17-crate workspace scaffold lands in Epic 1a, Story 1a.1.
