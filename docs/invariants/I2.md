# I2: Every IAC interaction is logged before delivery

See Architecture §3.2 for the full invariant definition and rationale.

## Enforcement Mechanism (v0.1-α type codification)

Type-level codification lives at `crates/maos-domain/src/invariants/i2.rs`:
the `InvariantI2` marker type anchors I2 in the type system. Runtime enforcement
ships in future stories per Architecture §3.2.1; at v0.1-α the type codification is
the structural enforcement anchor.

See Story 1a.1 for the type-codification rationale; Architecture §3.2 + §3.2.1
for the full enforcement matrix.

## v0.1-β runtime anchor

Story 1b.1 promotes I2 from structural type codification to runtime enforcement.
- `TransparencyLogAdapter::insert_frame_event` writes the Transparency Log row BEFORE delivery.
- `LogBeforeDeliver::new` constructor restricted via `#[doc(hidden)] pub` — typestate enforced by convention.
- Panic-on-write-failure path: kernel halts rather than silently dropping frames.
- Runtime body: `crates/maos-kernel-core/src/iac/transparency_log.rs`
