# MAOS Trademark Policy

This document describes the trademark usage guidelines for the MAOS name,
logo, and associated marks.

## The MAOS Name

"MAOS" (Multi-Agent Orchestration Substrate) is the name of this open-source
project. The name and any associated logos are trademarks of the MAOS project
maintainers.

## Permitted Uses

You MAY:

- Use "MAOS" to refer to this project in documentation, articles, tutorials,
  and presentations
- Use "MAOS" in the name of community plugins, integrations, and extensions
  that are compatible with the MAOS platform (e.g., "Spirit for MAOS",
  "MAOS integration")
- Use "MAOS" in academic and research publications that reference this project
- Fork the project under the Apache-2.0 / MIT license terms

## Restrictions

You MUST NOT:

- Use "MAOS" as the primary name of a product or service that is not this project
- Use "MAOS" in a way that implies official endorsement or affiliation without
  written permission from the maintainers
- Use the MAOS logo in modified form without permission
- Register "MAOS" or confusingly similar marks as trademarks in any jurisdiction

## Community vs Commercial

- **Community use** (open-source projects, blog posts, talks, educational
  materials) is freely permitted under the guidelines above.
- **Commercial use** (products, services, or marketing materials that use
  "MAOS" as a brand element) requires prior written approval from the
  project maintainers.

## Questions

For trademark usage questions, contact the maintainers via GitHub Issues or
the project's communication channels listed in `GOVERNANCE.md`.
