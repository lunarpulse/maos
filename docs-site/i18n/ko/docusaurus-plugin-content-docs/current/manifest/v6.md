# Manifest 스키마 v6 (현재)

스키마 v6는 `[capabilities.required.skill]`을 추가합니다. 기준 상수는
`maos-spirit-abi`의 `MANIFEST_SCHEMA_VERSION = 6`입니다. 스키마 v5의 선언도
계속 지원합니다. 다른 필드는 [스키마 v5](./v5)를 참고하세요.

```toml
[class]
name = "researcher"
version = "0.5.0"
abi = "1.0"
manifest_schema_version = 6
min_substrate_version = "0.1.0"
forms = ["rust-inproc"]
trust_tier = "local"
description = "Native Researcher"

[capabilities.required.skill]
author_self = true
```

`author_self`은 기본값이 `false`인 boolean이며 `Scope::SkillAuthorSelf`에
대응합니다. 알 수 없는 키와 boolean이 아닌 값은 거부합니다. 스키마 v6보다
낮은 manifest에서는 이 테이블을 제거하므로 skill 권한이 부여되지 않습니다.
테이블을 생략해도 권한이 없습니다.

이 선언은 capability로 중재된 제출을 허용할 뿐 활성화를 허용하지 않습니다.
모든 skill과 revision은 operator admission을 받아야 합니다. Policy, context
exhaustion, issuance quota는 선언된 capability도 거부할 수 있습니다. Native
Researcher port의 host가 author identity와 telemetry를 고정하므로 Spirit은
다른 pid를 지정하거나 telemetry를 조작할 수 없습니다. 이 선언은 WASM이나
TypeScript에 skill-authoring import를 추가하지 않습니다.

승인된 skill을 발견하는 것은 실행하는 것과 다릅니다. Revision은 결정만
기록하며 opaque diff를 자동 적용하지 않습니다. 수정된 문서도 별도로 제출하여
승인받아야 합니다.
