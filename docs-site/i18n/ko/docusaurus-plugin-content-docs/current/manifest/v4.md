# Manifest 스키마 v4 (현재)

스키마 v4는 선택적 `[capabilities.required.loom]` 선언을 추가합니다. 권위 있는 값은 `maos-spirit-abi`의 `MANIFEST_SCHEMA_VERSION = 4`입니다.

## `[capabilities.required.loom]`

이 섹션은 Spirit이 호출 시 요청할 수 있는 collective 범위를 선언합니다. 선언은 manifest에 명시되고 검토할 수 있지만, 로컬 manifest 파일은 발행자 서명으로 보호되지 않습니다.

| 필드 | 타입 | 기본값 | 어드미션 범위 |
|---|---|---|---|
| `read` | boolean | `false` | `LoomRead` |
| `write` | boolean | `false` | `LoomWrite` |
| `scan` | boolean | `false` | `LoomScan` |

```toml
[class]
manifest_schema_version = 4

[capabilities.required]
provider.complete = ["anthropic.claude-3-5-sonnet-20241022"]

[capabilities.required.loom]
read = true
write = true
scan = true
```

`write`는 짧은 수명의 high-privilege 토큰으로 발급되고 collective 경로에서 중재됩니다. 단위 범위는 팀 또는 namespace 제한을 표현하지 않으며, tenant map이 저장소에서 테넌트 선택을 시행합니다.
