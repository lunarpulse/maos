# Manifest 스키마 v1 (Historical)

스키마 v1은 **Epic 1b 기준** manifest 포맷입니다. 최초의 MAOS kernel과 함께 배포된 원래 manifest 형태입니다.

## 상태

**거부(N-2).** 현재 스키마 버전이 3 이상이면(`MIN_SUPPORTED_MANIFEST_SCHEMA_VERSION`이 1을 초과한 시점부터), kernel은 어드미션 시점에 v1 manifest를 `EAbiTooOld`로 거부합니다.

> v0.5-alpha에서는 하한선이 `1`로 유지되어 기존 manifest가 여전히 로드됩니다. Story 7.5a가 하한선을 올리면 v1은 영구적으로 거부됩니다.

## 섹션

스키마 v1은 핵심 manifest 섹션만 지원합니다:

- `[class]` — Spirit 신원(`name`, `version`, `min_substrate_version`, `manifest_schema_version`, `trust_tier`, `description`)
- `[author]` — 작성자 메타데이터
- `[budget]` — 리소스 예산(`context_window_size`, `time_cap_seconds`)
- `[capabilities.required]` — 필수 역량(capability)
- `[posture]` — Spirit 자세(posture) 설정
- `[output_shape]` — 출력 형태(output shape) 선언

## 마이그레이션

v1에서 v2로 마이그레이션하려면 [Manifest v2](./v2)를 참조하세요. 현재 스키마로 이동하려면 [v2 → v3 마이그레이션 가이드](/migrate/)를 참조하세요.

## 예시

```toml
manifest_schema_version = 1

[class]
name = "hello-spirit"
version = "0.1.0"
min_substrate_version = "0.1.0"
trust_tier = "sandboxed"
description = "A minimal Spirit for testing."

[author]
name = "MAOS Team"

[budget]
context_window_size = 4096
time_cap_seconds = 300

[capabilities.required]
```
