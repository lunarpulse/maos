# Trademark Policy

> **Full document:** [`TRADEMARK.md`](https://github.com/lunarpulse/maos/blob/main/TRADEMARK.md)

## Permitted Uses

- Refer to this project in documentation, articles, and presentations
- Name compatible plugins and integrations (e.g., "Spirit for MAOS")
- Academic and research publications referencing this project
- Fork under Apache-2.0 / MIT license terms

## Restrictions

- Do not use "MAOS" as the primary name of an unrelated product
- Do not imply official endorsement without written permission
- Do not register "MAOS" or confusingly similar marks

## Community vs Commercial

- **Community use** (open-source, blog posts, talks, education) is freely permitted
- **Commercial use** requires prior written approval from maintainers
