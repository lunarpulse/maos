# Governance

MAOS uses a maintainer-led, open contribution model.

> **Full document:** [`GOVERNANCE.md`](https://github.com/lunarpulse/maos/blob/main/GOVERNANCE.md)

## Model

The project is stewarded by a core maintainer team that makes final decisions
on direction, architecture, and releases. All contributions are welcome through
the standard pull request process.

## Roles

| Role | Responsibility |
|------|---------------|
| **Maintainer** | Merge authority, release management, architecture stewardship |
| **Reviewer** | Review, story validation, party-mode participation |
| **Contributor** | Pull requests, issue reports, documentation, RFC proposals |

## Decision-Making

- **Architecture decisions** follow the [ADR process](/community/rfc-template)
- **Feature proposals** use the [RFC process](/community/rfc-template)
- **Contentious decisions** use party-mode (multi-agent review panel)
- **Constitutional invariants** follow the amendment process per ADR-037

## Sustainability

The MAOS project intends to establish an Open Collective for transparent
sustainability funding. At launch this is a declared intent; fiscal sponsor
work is tracked as an initiated item.

See [`.github/FUNDING.yml`](https://github.com/lunarpulse/maos/blob/main/.github/FUNDING.yml).
