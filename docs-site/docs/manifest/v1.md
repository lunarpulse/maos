# Manifest Schema v1 (Historical)

Schema v1 is the **Epic 1b baseline** manifest format. It is the original manifest shape that shipped with the first MAOS kernel.

## Status

**Hard-refused (N-2).** The kernel rejects v1 manifests at admission with `EAbiTooOld` when the current schema version is 3 or higher (once `MIN_SUPPORTED_MANIFEST_SCHEMA_VERSION` is raised above 1).

> At v0.5-alpha the floor remains at `1` so legacy manifests still load. Once Story 7.5a lifts the floor, v1 will be permanently refused.

## Sections

Schema v1 supports only the core manifest sections:

- `[class]` — Spirit identity (`name`, `version`, `min_substrate_version`, `manifest_schema_version`, `trust_tier`, `description`)
- `[author]` — Author metadata
- `[budget]` — Resource budget (`context_window_size`, `time_cap_seconds`)
- `[capabilities.required]` — Required capabilities
- `[posture]` — Spirit posture configuration
- `[output_shape]` — Output shape declarations

## Migration

To migrate from v1 to v2, see [Manifest v2](./v2). To reach the current schema, see the [v2 to v3 migration guide](/migrate/).

## Example

```toml
manifest_schema_version = 1

[class]
name = "hello-spirit"
version = "0.1.0"
min_substrate_version = "0.1.0"
trust_tier = "sandboxed"
description = "A minimal Spirit for testing."

[author]
name = "MAOS Team"

[budget]
context_window_size = 4096
time_cap_seconds = 300

[capabilities.required]
```
