# Manifest Schema v4 (Current)

Schema v4 adds the optional `[capabilities.required.loom]` declaration. The authoritative value is `MANIFEST_SCHEMA_VERSION = 4` in `maos-spirit-abi`.

## `[capabilities.required.loom]`

This section declares the collective scopes a Spirit may request at call time. The declaration is manifest-declared and reviewable; local manifest files are not publisher-signed.

| Field | Type | Default | Scope admitted |
|---|---|---|---|
| `read` | boolean | `false` | `LoomRead` |
| `write` | boolean | `false` | `LoomWrite` |
| `scan` | boolean | `false` | `LoomScan` |

```toml
[class]
manifest_schema_version = 4

[capabilities.required]
provider.complete = ["anthropic.claude-3-5-sonnet-20241022"]

[capabilities.required.loom]
read = true
write = true
scan = true
```

`write` is issued as a short-lived high-privilege token and is mediated by the collective route. The unit scopes do not encode team or namespace restrictions; tenant selection is enforced by the store's tenant map.
