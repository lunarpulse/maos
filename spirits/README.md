# Spirits

This directory is a future home for **Reference Spirit crates** — canonical
Spirit implementations that ship with the MAOS substrate.

At v0.1-α this directory is empty. Reference Spirits land in future stories:

- `hello-spirit` — acknowledgement fixture (FR58; v0.1)
- `diagnostic-architect` — Mira/Nash bilateral pair (v0.5)
- `orchestrator` — epic decomposition and dispatch (v0.5)
- `butler` — proactive scheduling and calendar integration (v0.3)

See Architecture §6 (Reference Spirits) for the full roadmap.
